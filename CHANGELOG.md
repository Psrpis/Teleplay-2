# Changelog

All notable changes to TelePlay will be documented in this file.

## [2.0.0] - 2026-09-10

### Added
- **Mobile-First Bottom Navigation**: 4-tab architecture (`Home`, `Search`, `Library`, `More`) with glassmorphic styling and icons.
- **Tablet Navigation Rail**: Responsive layout for large screens, foldables, and tablets.
- **Home Hero Banner**: Featured media display with full backdrop, genres, quick resume, and details trigger.
- **Home Shelves**: Continue Watching with progress bars, Recently Added, Favorites, Recently Watched, and Collections with "See All" deep-links.
- **Instant Search with Filters**: Category chips for All, Movies, Series, and Actors, plus recent search history chips.
- **Unified Library Screen**: Segmented tabs for Continue Watching, Recently Added, Favorites, History, and Collections.
- **More Hub**:
  - Direct Movies browser with watched filter.
  - Series browser with season selector and episode list.
  - Actors directory and filmography viewer.
  - Statistics screen showing watch time, counts, and recent views.
  - Surprise Me random movie picker.
  - In-app Settings with server URL configuration.
- **MediaDetailSheet**: Bottom sheet with backdrop, poster, rating, synopsis, cast tags, and favorite/watched toggles.
- **GitHub Actions Release Dispatch**: Enhanced `.github/workflows/android-release.yml` with manual workflow dispatch and release notes support.

### Changed
- Bumped Android `versionCode` to `14` and `versionName` to `2.0.0`.
- Bumped project version to `2.0.0`.

## [1.3.1] - 2026-08-15
- Initial Mobile UI structure and basic media playback.
- Telegram bot integration enhancements.
